# 🏠 Home Automation

Xiaomi dehumidifier automation dashboard.
Auto-controls 2 dehumidifiers (드레스룸, 팬트리) based on humidity levels.
Data pushed every 15 minutes and displayed via GitHub Pages.

## Features
- Real-time device status (humidity, temperature, power, mode)
- 15-min automation cycle (active 08-22, quiet 22-08)
- Activity log with search & filter
- Humidity history chart
- GitHub Pages dashboard
